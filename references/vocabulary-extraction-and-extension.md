# 本卷词汇、搭配与语言点提取规范

## 提取范围
以试卷真实出现的材料、题干、选项、听力文本（若提供）和写作任务为主。分为：
1. **本卷核心词汇**：影响理解或直接考查的词。
2. **关键搭配与句块**：动词-名词、形容词-介词、动词-介词/副词、固定句型和语篇连接。
3. **熟词生义**：常见词在本语境中的非基础义。
4. **构词与词形**：词根词缀、派生、词性转换、词形变化。
5. **同义改写与辨析**：阅读题干和原文的对应表达、易混词。
6. **延伸拓展**：与主题、语义场或常见高考表达相关，但不是本卷直接考点的项目，必须单独标注“延伸”。

## 每个条目的字段
英文词/词组；音标（仅在可靠时）；词性/结构；本卷语境义；常见义；搭配与句型；自然例句及翻译；近义词区别；常见错误；来源题号/段落。搭配要给完整用法，不只列两个词。

## 选择原则
优先高价值、可迁移、反复影响理解或表达的词，不追求数量。避免把简单词汇堆成清单。一个词有多个义项时明确本卷使用哪一个。标出正式程度、褒贬、可数性、及物性和介词选择等关键限制。

## 延伸学习
围绕原文主题扩展词族、搭配网络、同义替换、反义对比、常见句型和语篇表达。每个拓展组至少提供一个可理解的语境例句。提供短篇填空/选词/改写练习与答案解析，让学生主动使用，而非只背列表。

## PDF 版式
建议按主题或词性组织，表格列宽适中；长例句改用分条卡片，避免挤成密集小字。中英文对照，题号来源可追溯。对多义词使用语境句，不脱离上下文。
