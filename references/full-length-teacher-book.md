# 全卷解析教辅硬性验收标准

## 成品结构
- 首页、目录、原卷（逐页原貌保留）、答案速查、逐题详解、知识点精讲与延伸、知识索引。
- 参考用户认可的专业教辅风格：题号清晰、红色答案、分级小标题、正文黑色、例句/语法结构易读；原卷必须在前，解释紧跟对应题目。
- 一般整卷原卷加解析可达数十页，但不设置凑字数目标；深度由题目复杂度决定。

## 每题固定内容
**【答案】** 明确答案或多种可接受答案。
**【题意与原文】** 必要原文句子与准确中文解释，不重复整篇材料以凑篇幅。
**【解题分析】** 逐步推理及证据位置。
**【逐项详解】** 每个选项/小问分别解释。
**【知识点精讲】** 完整解释规则、适用条件、例句、反例及与本题的关系。
**【知识延伸】** 相关语法/词汇/语篇方法，至少一则原创迁移例题并讲解（确有价值时）。
**【易错辨析】** 为什么学生会错、如何判断。

## 完成门槛
- 题号、答案、原文和页码一致；无漏项。
- 每条阅读推断有原文证据；每条语法解释可分析复核；范文满足任务约束。
- 缺音频、残缺图片或有争议答案必须如实标注；不把草稿标为最终版。
- PDF 逐页视觉检查：中文字体、英文连字、标点、上下标、图片清晰度、分页、孤行、目录页码。
- 输出验收报告，记录检查范围、待解决事项与完成状态。
