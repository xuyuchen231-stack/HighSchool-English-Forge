# Two-paper training and validation protocol

## Purpose
Use two real examinations to improve the reusable Skill workflow. This is evidence-based workflow calibration, not model fine-tuning and not proof of universal accuracy.

## Input profiles
- **Paper-only profile:** inspect every page and asset; solve independently; mark answer confidence; never invent an official key or missing listening transcript/audio.
- **Paper + key + audio profile:** solve independently first, then compare with the official key; use the audio/transcript to validate listening evidence; record discrepancies rather than silently copying the key.

## Required focused outputs
1. Contextual vocabulary and phrase bank from the actual paper, grouped by passage/section. Each entry includes phrase, contextual meaning, collocation/grammar pattern, natural example or transferable phrase, and source location.
2. Reading D analysis: paragraph function, text structure, question-by-question answer, exact evidence, paraphrase/inference chain, distractor diagnosis and a transferable solving rule.
3. Seven-option cloze analysis: answer per blank, preceding/following sentence clues, paragraph role, reference/connective/repetition/contrast logic, why the strongest distractor fails, and unused-option explanation.
4. Continuation writing: identify character state, central conflict, textual seeds, paragraph-starter function, one-sentence big idea, 4–6 causal small beats per paragraph, emotional/action line, language bank, plausible outcome and theme elevation.
5. Extension practice: new items tied to source vocabulary, inference, cohesion, and narrative logic; every task has an answer and explanation.

## Continuation-writing planning framework
- **Big idea:** express the character's change as A -> B, caused by a source-grounded event.
- **Small ideas:** convert each paragraph into 4–6 observable beats: stimulus -> reaction -> attempt -> setback/support -> progress/result.
- **Theme:** derive a concise universal insight from the demonstrated change. Do not append a generic slogan unrelated to the plot.
- **Continuity gate:** retain character traits, relationships, objects, setting and paragraph starters; no sudden cure, unsupported accident, arbitrary villain, or unexplained time jump.

## Validation record format
For each item record source, page, question ID, independently solved answer, official answer if supplied, evidence, confidence, reviewer status and unresolved issues. For each output record page/slide count and visual inspection status. A structural script pass is not a linguistic or visual pass.
