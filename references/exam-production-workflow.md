# 完整英语试卷生产工作流

## 0. 输入检查与交付约定
记录原文件名、SHA-256、页数、纸张尺寸、清晰度、考试省份/年份/题型、总分、考试时间。确认听力音频或权威听力原文是否提供。若用户只给部分页面，先明确覆盖范围。禁止凭常见卷型补写缺失题目。

建立机器可读清单：`page -> section -> question -> subpart/blank -> source coordinates`。每题唯一 ID；题号重复时加 section 前缀。将题目文字与原始页面位置关联，便于复核。

## 1. 独立作答与答案登记
先不读取外部答案。逐题作答并记录：
- answer / accepted alternatives
- exact evidence or grammatical rule
- reasoning steps
- why each distractor fails
- confidence: verified / probable / ambiguous / blocked
- source page and question ID

答案速查表、逐题解析、词汇索引必须由同一份答案登记表生成，避免互相矛盾。外部答案只用于事后核对，不可替代推理。

## 2. 各题型解析要求
### 阅读理解
每题依次写：考查目标（不作为唯一解释）→正确选项→原文证据（段落/句子）→题干与原文的改写对应→推理链→其他选项逐项排除→易错原因→可迁移方法。区分原文明确陈述、合理推断、作者态度和无依据猜测。

### 七选五/段落匹配
解释空格前后的逻辑、代词指代、连接词、重复词/同义复现、段落主题与结构功能。说明其余选项为什么不能接入上下文；解释两个未使用选项的迷惑性。

### 完形填空
每空检查词义、词性、搭配、语义褒贬、上下文逻辑、人物情绪、叙事时间线和篇章照应。给出完整句译文；每个干扰项说明不合语境之处，不可只写“意思不符”。

### 语法填空
先还原句子主干，再定位空格语法功能。说明为何用该词形、该时态/语态/非谓语/词性/单复数/比较级/冠词/介词等；如有可接受变体，明确适用语境。

### 语法选择、短文改错、翻译
逐个考点说明句法位置、语义和语域。翻译题逐个得分点对应到英文表达，区分必须表达的意义与可替换措辞。

### 听力
必须有实际音频或可追溯的权威文本。只有答案字母而无音频/原文，不能伪造听力证据。标注不可核验范围，并仅讲可验证部分。

### 应用文与读后续写
完整解析题目要求、受众、目的、语域、内容点、结构、词数和评分重点。读后续写还要检查人物设定、原文伏笔、段首句、因果连续性、情绪变化与结尾可信度。给出范文、逐句讲解和其他可行表达。

## 3. 原文证据标注
阅读篇章必须有证据标注版：在原始文本对应位置用颜色/下划线/编号标出证据句，并与题号关联。每题标注精确范围；若证据分散，使用多个标记并解释连接关系。不能把整段涂满来假装精确。原卷完整保留，另附标注副本，不覆盖原件。

## 4. 每题讲解模板
- 【答案】醒目、可直接核对。
- 【题目在问什么】用简明中文还原任务。
- 【关键依据】原文、语法位置或语境线索。
- 【一步步推理】逐步展示，不跳过关键环节。
- 【选项逐项分析】A-D逐项；填空题解释备选词/词形。
- 【长难句拆解】必要时拆主干、从句、非谓语、修饰关系。
- 【词汇与搭配】结合本题语境解释词义、词性、搭配和例句。
- 【知识精讲】补齐做懂本题所需的基础规则。
- 【迁移训练】原创同考点题目及完整答案解析。
- 【易错点】指出具体误区与避免方式。

多个题目共用同一基础知识时，可集中讲授，但每题的推理和选项仍须独立完成，不能用“见前文”替代核心解释。

## 5. PDF 结构
1. 封面与使用说明
2. 目录
3. 完整原卷（逐页原貌）
4. 答案速查（标注非官方/官方来源）
5. 逐题详细解析
6. 阅读证据标注页（或与每篇阅读解析紧邻）
7. 本卷词汇与搭配总表
8. 高频词组/熟词生义/构词法/语境辨析
9. 语言点延伸与易错辨析
10. 原创迁移练习与答案
11. 质量核验报告与来源说明

## 6. 独立复核
安排第二轮复核，尽量不展示第一轮答案，只给原题与证据。对答案差异回到原文、句法和语境裁决。对开放性表达保留合理答案范围。官方答案也可能存在印刷错误或争议，记录差异，不盲从。

## 7. 交付
文件命名清楚，原卷与解析版分开，PPT独立。QA报告列明题号覆盖、听力完整性、答案争议、来源、导出检查。未通过的项目不隐藏。
