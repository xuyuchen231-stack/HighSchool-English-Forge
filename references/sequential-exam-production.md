# Sequential Exam Production Protocol

## Non-negotiable sequencing
Process exactly ONE examination at a time. Never combine, compare, pool vocabulary across, or generate a shared answer key for multiple papers unless the user explicitly asks for a comparative study. If multiple papers are uploaded, register filenames and upload order, select the first paper only, and queue all others untouched. Do not start the next paper until the current paper has passed its chapter gates and the user has received its deliverables or explicitly changed scope.

Within one paper, process exactly ONE chapter/section at a time in printed order. A chapter is a coherent exam section or passage-based unit (Listening, Reading A/B/C/D, Seven-option task, Cloze, Grammar, Application Writing, Continuation Writing). Do not solve several sections in one batch.

For each chapter:
1. Inventory source pages, question numbers, options/blanks, figures and associated audio/transcript/key.
2. Read the complete chapter from the supplied source; preserve wording, order, numbering and terminology.
3. Solve independently before consulting an official key.
4. Build an answer ledger: question ID, answer, exact evidence/rule, reasoning, distractor analysis, confidence and verification status.
5. Explain every question and every option/blank. Reading requires exact sentence(s), paragraph function, paraphrase/inference chain and why each distractor fails. Listening requires transcript/audio time evidence when available.
6. Extract vocabulary/collocations only from this chapter. Include contextual meaning, part of speech, pattern, example, translation, register and common misuse. Label extensions separately.
7. Create targeted transfer exercises based on this chapter, with answers and explanations.
8. Independently review and reconcile official-key disagreements without silently changing source content.
9. Export a chapter PDF and QA record; reopen and render every page; inspect clipping, legibility, tables and annotations.
10. Stop. Report complete/partial/blocked and wait for the next instruction before processing another chapter.

Never claim a whole-paper package is complete while any chapter is unprocessed. Track: Not started / In progress / Drafted / Independently checked / Export checked / Accepted / Blocked.

## Missing material
If audio is missing, do not guess listening answers from options. Mark Listening Blocked and request audio or verified transcript. If no official key is supplied, label answers independently derived, not official. If scans are unclear, inspect page images and report unreadable spans. Never import keys or explanations from another paper.

## Chapter PDF output
Each chapter export contains scope/source pages, answer key, detailed item-by-item reasoning, reading evidence, chapter vocabulary/collocations, targeted exercises with full solutions, and QA limitations. Only after all chapters are accepted assemble the untouched original-paper PDF and complete answer-and-explanation PDF in original question order. A partial chapter export must never be labelled a complete solution PDF.

## Copyright
Do not commit user-provided exam scans, answer PDFs or audio to a public GitHub repository. Commit reusable protocols, templates and code only.
