# PDF / PPTX 交付验收

## PDF
- 原卷页面必须原样保留并位于前部；比较原文件与合并后前 N 页的渲染结果，不能只比较 PDF 对象或OCR文本。
- 答案速查、题解和词汇表题号一致；逐题覆盖清单无漏项。
- 中文字体嵌入或可靠替代；英文标点、音标、特殊符号显示正常。
- 检查页码、目录、书签、边距、图像清晰度、跨页标题、孤行、空白页和文字溢出。
- 逐页渲染并实际查看每一页。抽查不能标记为全量视觉验收。
- 阅读证据标注不得遮字，题号标签与解析对应。

## PPTX
- 文件可打开；每页比例16:9；字体、字号、配色、页码和页眉一致。
- 不允许文字溢出、被裁切、图表错位、英文断词、图片拉伸或空白占位。
- 逐页导出为图片或PDF并查看所有幻灯片。
- 英文表达进行语法、搭配、语域和自然度复核。
- 每个练习均有答案或明确的评分标准；开放题注明示例答案并非唯一答案。
- 小作文与读后续写均有基础和进阶教学，不可只在目录出现。
- 输出PPTX和预览PDF；若无法导出预览，明确说明。

## QA 报告
列出：输入文件、页数、题目总数、已解析题数、缺失音频/页面、答案争议、来源、自动检查结果、逐页视觉检查结果、PPT幻灯片数量及检查范围。结构检查不能替代语言审校。
